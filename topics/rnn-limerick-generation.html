The Task

The goal is to train a recurrent neural network that can generate text resembling limericks -- five-line poems with an AABBA rhyme scheme. The model learns character-by-character from a large corpus of limericks scraped from the web, then attempts to produce new ones from a seed prompt.

Data and Preprocessing

The training data consists of approximately 15 million characters of continuous limerick text with a vocabulary of 70 unique characters (lowercase letters, digits, punctuation, whitespace).

Each character is mapped to a unique integer index. The text is then sliced into overlapping sequences of fixed length (100 characters), where the target for each sequence is the next character. This produces around 149,000 training samples fed to the model in batches of 128.

Why character-level? Unlike word-level models, character-level models can learn spelling, punctuation patterns, and line structure from scratch -- important for reproducing the rhyme and rhythm of limericks.

Model Architecture

The network follows an Embedding → LSTM → Linear pipeline:

  • Embedding layer: Maps each of the 70 characters to a 64-dimensional dense vector
  • LSTM layer: 512 hidden units processing the embedded sequence with learned forget, input, and output gates
  • Linear layer: Projects the final hidden state back to 70 logits (one per character)

LSTM cell: the forget gate (f), input gate (i), and output gate (o) control information flow through the cell state

Why LSTM over vanilla RNN? Standard RNNs suffer from vanishing gradients on long sequences. The LSTM's gating mechanism allows it to retain information across the ~100-character window needed to capture limerick structure.

Training

The model was trained on GPU using PyTorch with the Adam optimizer and cross-entropy loss. Training was split into two phases to compare how additional training affects generation quality:

  • Phase 1: 2 epochs -- the model learns basic character distributions
  • Phase 2: 18 more epochs (20 total) -- the model refines its understanding of word boundaries, line breaks, and rhyme patterns

Model checkpoints were saved after each phase, enabling side-by-side comparison of generation quality at different training stages.

Text Generation

Generation uses autoregressive sampling: starting from a seed prompt, the model predicts the next character, appends it, and repeats. A temperature parameter controls randomness -- lower values produce more conservative (repetitive) text, while higher values increase diversity at the cost of coherence.

Analysis

2-epoch model: Generates mostly gibberish with occasional recognizable fragments. No limerick structure, no rhyme scheme, minimal word coherence.

20-epoch model: Shows clear improvement -- outputs resemble English words, line breaks appear in roughly the right places, and there are sporadic attempts at end-of-line rhyming. However, grammar remains poor and content is nonsensical.

This progression demonstrates how character-level RNNs gradually learn hierarchical structure: first individual characters, then character combinations (spelling), then word boundaries, and finally higher-level patterns like line structure and rhyme.

Takeaways

  • Character-level LSTM can learn basic text structure from raw characters alone, but generating coherent poetry requires significantly more capacity or training
  • Model saving and loading is essential for iterative training -- splitting training into phases enables checkpoint comparison without retraining from scratch
  • Temperature-controlled sampling provides a useful trade-off between diversity and coherence during generation
  • GPU acceleration was critical for the 15M-character dataset -- training on CPU would have been impractical
