Background

Image-guided therapy (IGT) relies on real-time ultrasound imaging to visualize anatomical structures and surgical instruments during procedures. Automatic object detection in ultrasound images can significantly improve surgical precision by identifying critical structures like needles, catheters, and anatomical landmarks.

I extended the IGTPrototypingTool to include real-time object detection capabilities using OpenCV algorithms. The goal was to automatically detect objects in ultrasound images and provide measurement tools to help clinicians during procedures.

Contributions

Core Functionality

  • Real-time Data Integration: Created a new tab for Object Detection that loads ultrasound real-time data from a frame grabber
  • Circle/Sphere Detection: Implemented and tested Hough Circle Detection algorithm to identify circular structures in ultrasound images
  • Distance Measurement: Added functionality to measure the distance between two points in the ultrasound image (in pixels)
  • Line Detection: Tested and implemented multiple line detection algorithms including RANSAC and Hough Line Transform for needle detection
  • Configurable UI: Added UI controls to adjust algorithm parameters in real-time (thresholds, sensitivity, etc.)
  • Spacing Calibration: Performed spacing calibration to convert pixel measurements to millimeters for clinical use
Repository: IGTPrototypingTool-ObjectDetection

Methodology

Image Preprocessing

To improve algorithm performance, I implemented automatic image enhancement that modifies the initial images before applying detection algorithms. This includes threshold adjustments and noise reduction techniques specific to ultrasound imaging.

Line Detection Algorithms

I tested two main approaches for line detection:

  • RANSAC Algorithm: More robust to outliers, provides higher accuracy for needle detection. Line 1 in the results shows excellent performance corresponding to the needle position.
  • Hough Line Transform: Classic computer vision approach, faster but less robust to noise in ultrasound images

Circle Detection

Used the Hough Circle Detection algorithm to identify spherical structures. This is particularly useful for detecting circular anatomical features or calibration markers.

Calibration System

Implemented a spacing calibration system to convert pixel-based measurements to real-world millimeter measurements. This is critical for clinical applications where accurate measurements are required.

Challenges & Solutions

Ultrasound Image Quality

Challenge: Ultrasound images contain significant noise, speckle artifacts, and acoustic shadows that can interfere with object detection.

Solution: Implemented automatic preprocessing with adaptive thresholding to enhance image quality before detection.

Real-time Performance

Challenge: Object detection needs to run in real-time during procedures without lag.

Solution: Optimized algorithm parameters and used efficient OpenCV implementations to maintain real-time frame rates.

Calibration Accuracy

Challenge: Converting pixel measurements to millimeters requires accurate calibration for each ultrasound setup.

Solution: Developed a calibration system using known reference markers in the water bath.
